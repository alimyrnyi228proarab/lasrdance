# Personal Portfolio Website

## About the Project

This project is a personal portfolio website created using HTML, CSS, and JavaScript. It presents personal information, skills, projects, and contact links in a modern and responsive design.

## Features

- **Responsive Design** — adapts to desktop, tablet, and mobile screens.
- **Dark and Light Mode** — allows users to switch between two themes.
- **Portfolio Section** — displays projects and images.
- **About Me Section** — provides personal information.
- **Skills Section** — displays technical skills.
- **Search Function** — allows users to search through portfolio content.
- **Social Media Links** — provides links to social profiles.
- **Hover Effects** — adds interactive visual effects to buttons and links.

## Technologies Used

- HTML5 — website structure.
- CSS3 — styling, Flexbox, Grid, Media Queries, and responsive design.
- JavaScript — theme switching and interactive functionality.

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. You can also use the Live Server extension in Visual Studio Code.

## JavaScript Functions

### 1. Theme Switching
Allows users to switch between dark and light modes by clicking the theme button.

### 2. Search Function
Allows users to search and filter portfolio content.

### 3. Interactive Elements
Handles button clicks and other interactive website elements.

## Responsive Design

The website uses CSS Media Queries to adapt to different screen sizes:

- 1024px — tablets.
- 768px — mobile devices.
- 400px — small mobile devices.
